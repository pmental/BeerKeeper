# Beer styles for BeerKeeper
#
# One style per line. Blank lines and lines starting with "#" are ignored.
# This list seeds the beer_styles TABLE, once, the first time the app
# boots with an empty database. From that point on, styles are managed
# from the admin page's "Beer Styles" panel, not this file - editing it
# after first boot has no effect. If this install previously used the
# old file-based version (a hand-edited beer_styles.txt in your data
# directory), that file's contents were migrated in automatically instead
# of this bundled list, preserving any customizations.
#
# Starting point compiled from the general/public beer style taxonomy
# (style names only - no descriptions), organized similarly to how
# BeerAdvocate groups its own style guide. Add, remove, rename, or
# reorder freely; styles here are just suggestions offered while typing,
# never a restriction on what you can enter.
