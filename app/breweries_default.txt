# Breweries for BeerKeeper
#
# One brewery per line: either just a name, or "Name | https://website.com"
# if you want a website attached. Blank lines and lines starting with "#"
# are ignored.
#
# This file seeds the breweries TABLE, once, the first time the app boots
# with an empty database - unlike beer_styles.txt (which is read fresh on
# every request), these become real Brewery rows from that point on and
# are managed like any other brewery: rename, delete, or add more through
# the app itself. Editing this file after first boot has no effect; it's
# only a seed, not a live source. See the README for details.
#
# Compiled from public sources (mainly a mix of Wikipedia and craft-beer
# press coverage, cross-checked where possible) - not an exhaustive or
# official registry, and brewery details (name spelling, active status)
# can drift over time. It's just a helpful starting point; add, remove,
# or fix entries freely through the app once it's running.
